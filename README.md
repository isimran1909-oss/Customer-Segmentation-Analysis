# Customer-Segmentation-Analysis
Customer Segmentation Analysis using Python, Pandas, NumPy and Power BI# Customer Segmentation Analysis Using Python and Power BI

## Project Overview

This project demonstrates an end-to-end data analytics workflow using an AI-generated e-commerce dataset.

The dataset contained data quality issues such as missing values, duplicate records, inconsistent formats, and invalid entries. Python was used to clean and preprocess the data before building interactive dashboards in Power BI.

## Objectives

* Clean and transform raw e-commerce data
* Perform customer segmentation analysis
* Analyze sales and revenue trends
* Evaluate seller performance
* Examine payment methods and order status
* Generate business insights through visualizations

## Tools Used

* Python
* Pandas
* NumPy
* Power BI
* DAX

## Key Analyses

* Customer Segmentation
* Revenue by Category
* Revenue by Country
* Product Demand Analysis
* Order Status Analysis
* Return Request Analysis
* Payment Method Analysis
* Seller Performance Analysis
